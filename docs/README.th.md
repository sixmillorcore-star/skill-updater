# Skill Updater สำหรับ Codex และ Claude Code บน Windows

โปรแกรมขนาดกะทัดรัดสำหรับตรวจหา Skill ที่ติดตั้งอยู่ ตรวจสอบเวอร์ชันจากต้นทางที่รองรับ และอัปเดตรายการที่พร้อมได้ในหน้าต่างเดียว เลือกใช้งานเองหรือตั้งให้อัปเดตทุกเช้าเวลา 08:00 พร้อมเปิดหน้าต่างตรวจสอบหลังเข้า Windows ได้

[ดาวน์โหลดรุ่นล่าสุด](https://github.com/sixmillorcore-star/skill-updater/releases/latest) · [English](../README.md) · [ผลการทดสอบ](VALIDATION.md)

## เริ่มใช้งาน

ต้องมี Windows, .NET Framework และ Windows PowerShell 5.1 หากต้องการอัปเดตปลั๊กอิน ต้องมี CLI ของ Codex หรือ Claude Code ที่เกี่ยวข้องด้วย ไม่จำเป็นต้องติดตั้งทั้งสองแอป

1. ดาวน์โหลด ZIP จากหน้า [Releases](https://github.com/sixmillorcore-star/skill-updater/releases/latest) แล้วแตกไฟล์ทั้งโฟลเดอร์
2. เปิด `SkillUpdater.exe` โดยเก็บสคริปต์ PowerShell, โฟลเดอร์ `languages`, ไอคอน และ `settings.json` ไว้ข้างโปรแกรม
3. กด **Check again** เพื่อตรวจสอบรายการและเวอร์ชัน กด **Update ready** เมื่อมีรายการที่รองรับและพร้อมอัปเดต
4. กด **Aa** เพื่อเลือกภาษา ฟอนต์ และขนาดข้อความ

ปุ่มอัปเดตทำงานกับทุกรายการที่พร้อม รวมรายการที่ซ่อนอยู่ด้วยตัวกรอง ส่วนการตรวจสอบเวอร์ชันไม่สั่งติดตั้งอัปเดต

## ความสามารถ

- ตรวจ Skill ของผู้ใช้ ระบบ โปรเจกต์ที่รู้จัก และปลั๊กอินที่ยังติดตั้งอยู่ของทั้ง Codex และ Claude Code
- กรองตามแอป และค้นหาจากชื่อ Skill สถานะ ต้นทาง หรือที่อยู่ไฟล์
- สำรองโฟลเดอร์ Skill ก่อนการอัปเดตที่รองรับ และเก็บผลการทำงานไว้ใน `data`
- หน้าต่างสีดำ ย่อได้ถึง 640 × 460 พร้อมรายละเอียด 4 บรรทัดเต็ม ข้อความยาวเลื่อนอ่านและคัดลอกต่อได้
- มีเมนู 20 ภาษา ค่าเริ่มต้นตามภาษา Windows ภาษาที่ไม่มีคำแปลจะระบุ English fallback

ภาษาที่มีคำแปล: ไทย อังกฤษ ญี่ปุ่น จีนตัวย่อ จีนตัวเต็ม เกาหลี เยอรมัน ฝรั่งเศส สเปน โปรตุเกส อิตาลี รัสเซีย เวียดนาม อินโดนีเซีย อาหรับ ฮินดี ตุรกี ยูเครน ดัตช์ และโปแลนด์

## ตั้งเวลาและเปิดหลังเข้า Windows

หากต้องการใช้ตารางเวลา ให้รัน `Install.cmd` จากโฟลเดอร์โปรแกรม ระบบจะสร้างทางลัดและงานสำหรับผู้ใช้ปัจจุบันด้วยสิทธิ์แบบจำกัด

| เวลา | การทำงาน |
| --- | --- |
| ทุกวัน 08:00 ตามเวลาเครื่อง | อัปเดตรายการที่รองรับและแสดงผล เมื่อเครื่องเปิดอยู่ก่อน 08:00 และผู้ใช้เข้า Windows แล้ว |
| หลังเข้า Windows ประมาณ 20 วินาที | เปิดหน้าต่างตรวจสอบให้เลือกกดอัปเดตเอง |

หากพลาดเวลา โปรแกรมจะไม่อัปเดตย้อนหลังอัตโนมัติและไม่ปลุกเครื่อง ขณะหน้าต่างเปิดอยู่จะตรวจหา Skill ใหม่ประมาณทุก 5 นาที

เก็บโฟลเดอร์ที่ติดตั้งไว้ที่เดิม หากต้องการย้าย ให้รัน `Uninstall.cmd` จากที่เดิมก่อน แล้วรัน `Install.cmd` ในที่ใหม่ การถอนตารางเวลาไม่ลบ Skill หรือปลั๊กอิน

## รายการที่อัปเดตได้และข้อจำกัด

การตรวจพบ Skill ไม่ได้หมายความว่าจะอัปเดตทุกชนิดได้ โปรแกรมแสดงสถานะตามต้นทางของแต่ละรายการ

| ต้นทาง | การดูแลเวอร์ชัน |
| --- | --- |
| ปลั๊กอิน Codex ที่ติดตั้งอยู่ | ใช้ข้อมูลเวอร์ชันที่มีและ Codex CLI สำหรับรายการที่รองรับ ข้อมูล Catalog อาจเป็นแคช |
| ปลั๊กอิน Claude Code ที่ติดตั้งอยู่ | ใช้เวอร์ชันจาก marketplace ในเครื่องที่ยืนยันได้ และ Claude Code CLI โดยคง scope เดิม |
| System, runtime, app-managed หรือ Skill ที่ซิงก์มา | แสดงสถานะและให้แอปหรือต้นทางเดิมดูแลเวอร์ชัน |
| Local Skill | อัปเดตเฉพาะรายการที่ตั้งต้นทาง local ซึ่งรองรับไว้ชัดเจน หากไม่มีต้นทางจะแสดงให้ดูแลเอง |

ไฟล์ที่แก้ต่างจาก baseline จะถูกข้าม รายการที่ปิดใช้งานจะแสดงไว้แต่ไม่อัปเดต โปรแกรมไม่ติดตั้ง Skill ใหม่ทั้งหมดและไม่ติดตั้งปลั๊กอินที่ถอนออกแล้วกลับมา

## การตั้งค่าและข้อมูลในเครื่อง

โปรแกรมค้นหาจากตำแหน่งมาตรฐาน รวมถึง `CODEX_HOME` และ `CLAUDE_CONFIG_DIR` เมื่อกำหนดไว้ และตรวจเฉพาะโปรเจกต์ที่รู้จักแทนการกวาดทั้งไดรฟ์

เพิ่มตำแหน่งค้นหาใน `settings.json` ผ่าน `skillRoots`, `claudeSkillRoots`, `sharedSkillRoots` หรือ `projectRoots` และกำหนดต้นทาง local ที่รองรับใน `localSources` ไฟล์ตั้งค่าที่แจกไม่มีที่อยู่ส่วนตัวของเครื่องผู้พัฒนา

ค่าภาษาและฟอนต์อยู่ใน `data/ui-preferences.json` ส่วนรายงาน ประวัติ และสำเนาสำรองอยู่ใน `data` เช่นกัน ข้อมูลเหล่านี้อาจมีที่อยู่ไฟล์ในเครื่อง จึงควรเก็บไว้เป็นส่วนตัว

ตัว Updater ไม่ต้องใช้ AI API key การตรวจและอัปเดตเวอร์ชันใช้เครื่องมือของผู้ให้บริการที่ติดตั้งอยู่กับต้นทางที่ตั้งค่าไว้

## สร้างโปรแกรมจากซอร์ส

ใช้ C# compiler ของ .NET Framework บน Windows โดยไม่ต้องติดตั้ง Node.js หรือ web runtime เพิ่ม

```powershell
git clone https://github.com/sixmillorcore-star/skill-updater SkillUpdater
cd SkillUpdater
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1
.\SkillUpdater.exe
```

สร้าง EXE ก่อนรัน `Install.cmd` หากต้องการเปิดใช้งานเองอย่างเดียว สามารถเปิด EXE โดยไม่ติดตั้งตารางเวลาได้

## การทดสอบ

ตรวจหน้าต่างขนาดเล็กสุดครบ 20 ภาษาและ 5 ขนาดตัวอักษร รวมถึงการเลื่อนรายละเอียดไปท้ายข้อความ ดูขอบเขตและวิธีทดสอบซ้ำใน [เอกสารการทดสอบ](VALIDATION.md)

ฝั่ง Claude Code ทดสอบด้วยไฟล์ ทะเบียน และ CLI จำลอง ไม่ได้อ้างว่าได้ทดสอบอัปเดตปลั๊กอิน Claude Code จริงในสภาพแวดล้อมพัฒนาเดิมแล้ว
